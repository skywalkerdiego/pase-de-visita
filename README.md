# Pase de Visita · ENARM

App de estudio para el ENARM pensada para iPhone: tarjetas con repetición espaciada, casos clínicos con el porqué de cada opción, rutas de decisión, cuadros comparativos, simulacro con reloj y bitácora de errores.

Ábrela en Safari y agrégala a tu pantalla de inicio: funciona sin internet y guarda tu avance en el teléfono.

https://skywalkerdiego.github.io/pase-de-visita/
